# Smart Extract (智能解压缩) — 语言字符串

"Smart Extract" 功能新增的界面字符串**不在源码构建内**——7-Zip 的翻译通过
安装目录 `Lang\` 下的语言文件（`.txt`/`.ttt`，同一格式）单独分发。
因此要让界面显示"智能解压缩"，需要把这些字符串合并进语言文件。

## 字符串格式（Common/Lang.cpp 的 CLang 解析器）

语言文件是"行式"格式，**不是** `id=value`：

```
;!@Lang2@!UTF-8!      ← 签名行（必须第一行）
; 注释行               ← 每个注释/空行使运行 ID 自增 1
0                     ← 纯数字行：把运行 ID 设为该值
7-Zip                 ← 值行：当前 ID 的翻译，然后 ID 自增 1
540
打开(&O)              ← ID 540 的翻译
```

显式数字行可以向前跳（必须 ≥ 当前运行 ID，否则整个文件解析失败并回退英文）。

## 本功能新增的字符串

| ID   | 用途                                            | 中文建议值 |
|------|-------------------------------------------------|------------|
| 560  | 7zFM File 菜单项（右键菜单同一模板）            | `智能解压缩(&S)` |
| 2331 | 资源管理器右键菜单项 + Tools>Options 列表条目   | `智能解压缩` |
| 7220 | （保留）FM 字符串表                             | `智能解压缩` |
| 7221 | 加密包回退提示消息（7zFM 路径）                 | 见 patch-lang.py |

## 方法一（推荐）：patch-lang.py 自动合并

```cmd
python DOC\SmartExtract\patch-lang.py "C:\Program Files\7-Zip\Lang\zh-cn.txt"
```

- 脚本模拟解析器找到每个 ID 的准确落点，幂等（重复运行无副作用），
  插入点若不安全（会挤动后续翻译）会拒绝并提示手工处理。
- 需要管理员权限写 Program Files；建议先备份原文件。
- 本仓库 `DOC/SmartExtract/Lang/zh-cn.txt` 是基于 26.03 官方简中翻译
  已合并好的成品，可直接覆盖使用。

完成后重启 7-Zip File Manager 和资源管理器。

## 方法二：CI 安装包已内置

自 commit（见 git log）起，CI 在组装安装包时会把
`DOC/SmartExtract/Lang/zh-cn.txt` 覆盖进载荷的 `Lang\`，新装的 7-Zip
直接显示"智能解压缩"，无需手工操作。

## 注意

- ID 必须保持不减；插入位置错误会让整个语言文件解析失败（回退英文）。
- 值行内的 `\n` 是换行转义。
- `0` 之后的第一行必须是 `7-Zip`（签名校验）。
- 简体中文文件是 `zh-cn.txt`（24+ 版本用 .txt；旧版为 .ttt，格式相同）。
